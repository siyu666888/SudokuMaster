# 成就墙设计说明（Sudoku Master · v1.8.0）

> 本文档描述「成就」页（成就墙 + 统计区）的完整设计规范与实现代码。
> 对应版本：versionCode 15 / versionName 1.8.0（2026-10-19）。
> 页面入口：底部导航「成就」Tab（`Routes.ACHIEVEMENTS`），对局中隐藏底栏。

---

## 1. 设计目标

1. **一屏看全**：全局统计（总量 / 平均 / 连续 / 地狱）→ 明细 → 分布 → 成就墙，信息密度自上而下递减。
2. **状态自解释**：已解锁 / 未解锁一眼可分，无需图例。
3. **全主题一致**：所有高亮态绑定全局主题色（蓝 / 绿 / 灰 × 浅色 / 深色 × 标准 / 大号字），不出现孤立色。
4. **难度语义全局统一**：难度色条 + 难度图标在首页、历史、成就三处同色、同形、同位。

### 3.4 难度色彩与图标语义（全局唯一来源）

来源：`domain/model/BoardModels.kt`（色值）+ `util/DifficultyIcon.kt`（图标）。

| 难度 | 色值 | 图标 | 语义 |
| --- | --- | --- | --- |
| 简单 Easy | `#3fb950` 绿 | SentimentVerySatisfied | 笑脸 |
| 普通 Normal | `#2f6fed` 蓝 | SentimentNeutral | 平静脸 |
| 困难 Hard | `#d29922` 黄 | SentimentDissatisfied | 难过脸 |
| 专家 Expert | `#bc4cff` 紫 | MilitaryTech | 奖章 |
| 地狱 Hell | `#e0483b` 红 | LocalFireDepartment | 火焰 |

> 三处使用规范（必须一致）：
> - **首页难度卡**：色条 + 30dp 图标（tint=难度色）
> - **历史记录卡**：色条 + 18dp 图标（tint=难度色，位于名称左侧）
> - **成就墙卡片**：色条 + 18dp 图标（tint=难度色，位于名称左侧；未解锁压暗）
>
> 注意：成就卡行尾的奖杯/锁是**解锁状态**语义，与难度图标分工不同，故分行尾避免三图标并列拥挤。

## 4. 交互规范

| 手势 | 作用对象 | 行为 |
| --- | --- | --- |
| 点击 | 全部卡片 | `onStartLevel(sizeId, diffId)` → `Routes.newGame` → GameScreen `mode=new` 直接开局（通关计入成绩） |
| 长按 | 仅已解锁卡片 | 唤起系统分享面板（`ACTION_SEND` / `text/plain`），文案：「我在《数独大师》完成了「九宫格 · 地狱」，共 3 局，最快 03:53，最高 1200 分！快来挑战吧～」（无评分时省略最高分） |
| 按下（瞬态） | 全部卡片 | 见 §5 动效；松开恢复，不产生常驻选中态（点击即导航，无常驻选中语义） |

实现要点：`combinedClickable(interactionSource, LocalIndication.current)`——需要自定义 `MutableInteractionSource` 以同时观察按下态做发光，故加 `@OptIn(ExperimentalFoundationApi::class)`。

## 5. 动效规范

| 动效 | 参数 | 实现 |
| --- | --- | --- |
| 入场弹入 | 延迟 `index × 45ms`（全局序号错峰）；`enter 0→1`，scale `0.92→1`，alpha `0→1` | `LaunchedEffect` + `animateFloatAsState` + `graphicsLayer` |
| 按下反馈 | `press 0→1`：scale `×(1−0.035×press)`、背景 alpha `+0.05`（已解锁）/ `+0.08`（未解锁）；**无发光阴影**（v1.8.0 去除） | `collectIsPressedAsState` + `animateFloatAsState` |
| 分布条 | `animateFloatAsState` 宽度过渡；最小可见宽度 1.5% | `DistributionBar` |
| 缩放合成 | `totalScale = (0.92+0.08×enter) × (1−0.035×press)`（入场与按下相乘，不互相覆盖） | `graphicsLayer` |

> **v1.8.0 扁平化原则**：成就卡去除一切边框 / 阴影 / 线宽，状态仅由「底色 + 难度色条 + 图标 + 文案」表达；
> 难度色条（5dp）与难度图标保持不变。页面顶部汇总卡与 ModuleCard 维持原有浅阴影层次，未随扁平化。

## 6. 主题与适配

- **主题色**：全部取自 `MaterialTheme.colorScheme`（由 `SudokuMasterTheme` 按设置注入），切换蓝 / 绿 / 灰配色时成就页高亮态整体跟随。
- **浅色 / 深色**：`lightColorScheme` / `darkColorScheme` 自动切换；未解锁卡的灰度表达使用 `onSurfaceVariant` 系，两种模式下均有对比。
- **字体缩放**：`scaledTypography`（大号字 ×1.18）作用于全部文字；卡片高度固定 142dp，大字号下数据行靠 18sp 行高 + maxLines=1 省略号保证不溢出。
- **难度色**为固定品牌色，不随主题切换——这是有意的：难度色是全 App 语义色，三处必须一致。

## 7. 数据来源

`viewmodel/AchievementsViewModel.kt`（Room `game_records` → StateFlow）：

| 数据 | 类型 | 说明 |
| --- | --- | --- |
| `rows` | `List<AchRow>` | 全部 10 个（尺寸 × 难度）组合，含未解锁；`color` 为难度色 |
| `totalCount` / `hellCount` / `bestOverall` | `StateFlow` | 汇总卡 |
| `overview` | `StatsAnalyzer.Overview` | total / avgTimeMs / bestTimeMs / currentStreakDays / longestStreakDays / activeDays |
| `groupStats` | `List<StatsAnalyzer.GroupStat>` | 各难度聚合（局数降序），驱动分布条 |
| `lastPlayed` | `StateFlow<Long?>` | 最近一局时间（分组标题） |

```kotlin
data class AchRow(
    val sizeId: String, val diffId: Int,
    val sizeName: String, val diffName: String,
    val count: Int, val best: Long?, val avg: Long?,
    val bestScore: Int?,      // 最高得分（旧记录无评分时为 null）
    val color: Color
)
```

/**
 * 成就网格卡片（v1.8.0：去除边框 / 阴影 / 线宽，仅保留底色与难度色条）。
 * 已解锁：主题主色淡背景，奖杯/局数统一主题色；
 * 未解锁：低饱和灰底 + 「前往挑战」引导（无多余装饰线）。
 * 左侧竖条 + 名称前图标为该难度专属色/图标（与历史记录、首页难度卡一致）。
 * 交互：点击进入该难度新局；长按（已解锁）分享成绩；按下时微缩放 + 底色加深反馈；
 * 入场时按序号错峰弹入（奖杯弹出感）。
 */
@OptIn(ExperimentalFoundationApi::class)
@Composable
private fun AchievementCard(
    row: AchRow,
    index: Int,
    onClick: () -> Unit,
    onShare: () -> Unit,
    modifier: Modifier = Modifier
) {
    val unlocked = row.count > 0
    val shape = RoundedCornerShape(16.dp)
    val barColor = difficultyColor(row.sizeId, row.diffId)

    // 入场动画：按全局序号错峰弹入
    var appeared by remember { mutableStateOf(false) }
    LaunchedEffect(Unit) {
        kotlinx.coroutines.delay(index * 45L)
        appeared = true
    }
    val enter by animateFloatAsState(if (appeared) 1f else 0f, label = "card-enter")

    // 按下态：微缩放 + 背景微变（无发光阴影）
    val interactionSource = remember { MutableInteractionSource() }
    val pressed by interactionSource.collectIsPressedAsState()
    val press by animateFloatAsState(if (pressed) 1f else 0f, label = "card-press")

    val baseBgAlpha = if (unlocked) 0.10f else 0.35f

@Composable
private fun DistributionBar(label: String, count: Int, total: Int, color: Color) {
    val target = if (total > 0) count.toFloat() / total else 0f
    val frac by animateFloatAsState(targetValue = target, label = "dist")
    val percent = (target * 100).toInt()
    Column(modifier = Modifier.padding(vertical = 5.dp)) {
        Row(
            modifier = Modifier.fillMaxWidth(),
            horizontalArrangement = Arrangement.SpaceBetween
        ) {
            Text(label, style = MaterialTheme.typography.bodyMedium)
            Text(
                "$count 局 · $percent%",
                style = MaterialTheme.typography.labelLarge,
                color = color,
                fontWeight = FontWeight.SemiBold
            )
        }
        Spacer(Modifier.height(4.dp))
        Box(
            modifier = Modifier
                .fillMaxWidth()
                .height(8.dp)
                .clip(RoundedCornerShape(4.dp))
                .background(MaterialTheme.colorScheme.surfaceVariant)
        ) {
            Box(
                modifier = Modifier
                    .fillMaxWidth(frac.coerceIn(0.015f, 1f))
                    .fillMaxHeight()
                    .background(color, RoundedCornerShape(4.dp))
            )
        }
    }
}

package com.example.sudokumaster.viewmodel

import androidx.compose.ui.graphics.Color
import androidx.lifecycle.ViewModel
import androidx.lifecycle.viewModelScope
import com.example.sudokumaster.data.repository.StatsRepository
import com.example.sudokumaster.domain.game.StatsAnalyzer
import com.example.sudokumaster.domain.model.BoardDefinitions
import com.example.sudokumaster.domain.model.SizeId
import com.example.sudokumaster.domain.model.WinRecord
import com.example.sudokumaster.util.colorHex
import kotlinx.coroutines.flow.SharingStarted
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.flow.map
import kotlinx.coroutines.flow.stateIn

/** 成就列表中的一行。 */
data class AchRow(
    val sizeId: String,
    val diffId: Int,
    val sizeName: String,
    val diffName: String,
    val count: Int,
    val best: Long?,
    val avg: Long?,
    val bestScore: Int?,   // 最高得分（旧记录无评分时为 null）
    val color: Color
)

class AchievementsViewModel(private val container: AppContainer) : ViewModel() {
    private val statsRepo = container.statsRepository

    private val records = statsRepo.allRecords()

    val totalCount: StateFlow<Int> = records.map { it.size }
        .stateIn(viewModelScope, SharingStarted.WhileSubscribed(5000), 0)

    val hellCount: StateFlow<Int> = records.map { list ->
        list.count { it.sizeId == SizeId.NINE.id && it.diffId == 5 }
    }.stateIn(viewModelScope, SharingStarted.WhileSubscribed(5000), 0)

    val bestOverall: StateFlow<Long?> = records.map { list -> list.minOfOrNull { it.timeMs } }
        .stateIn(viewModelScope, SharingStarted.WhileSubscribed(5000), null)

    /** 最近一局完成时间（空列表为 null）。 */
    val lastPlayed: StateFlow<Long?> = records.map { list -> list.firstOrNull()?.date }
        .stateIn(viewModelScope, SharingStarted.WhileSubscribed(5000), null)

    /** 丰富统计：平均耗时 / 连续获胜天数 / 活跃天数等。 */
    val overview: StateFlow<StatsAnalyzer.Overview> = records
        .map { list -> StatsAnalyzer.overview(list.map { WinRecord(it.sizeId, it.diffId, it.timeMs, it.date) }) }
        .stateIn(viewModelScope, SharingStarted.WhileSubscribed(5000), StatsAnalyzer.Overview())

    /** 各难度通关分布（仅含有记录的难度，局数降序）。 */
    val groupStats: StateFlow<List<StatsAnalyzer.GroupStat>> = records
        .map { list -> StatsAnalyzer.byDifficulty(list.map { WinRecord(it.sizeId, it.diffId, it.timeMs, it.date) }) }
        .stateIn(viewModelScope, SharingStarted.WhileSubscribed(5000), emptyList())

    /** 成就墙：全部 (尺寸:难度) 组合，含未解锁。 */
    val rows: StateFlow<List<AchRow>> = records.map { list ->
        BoardDefinitions.TYPES.flatMap { bt ->
            bt.diffs.map { d ->
                val same = list.filter { it.sizeId == bt.size.id && it.diffId == d.id }
                AchRow(
                    sizeId = bt.size.id,
                    diffId = d.id,
                    sizeName = bt.size.label,
                    diffName = d.name,
                    count = same.size,
                    best = same.minOfOrNull { r -> r.timeMs },
                    avg = same.map { r -> r.timeMs }.average().takeIf { same.isNotEmpty() }?.toLong(),
                    bestScore = same.map { r -> r.score }.filter { it > 0 }.maxOrNull(),
                    color = colorHex(d.color)
                )
            }
        }
    }.stateIn(viewModelScope, SharingStarted.WhileSubscribed(5000), emptyList())
}
